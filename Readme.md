# Office SimInstall
Simulador sin instalacion y activacion de Office directa, solo con el apartado de juegos (Abrir el PowerShell como Administrador) y copiar el siguiente comando en la terminal:
```text
iex "& { $(irm https://raw.githubusercontent.com/WenliangK/OfficeAutoInstall/main/Simulador_Office_Linux.ps1) }"
```
